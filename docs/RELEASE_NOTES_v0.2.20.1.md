# Sub2API 0.2.20.1

本版本在 GN2API 现有定制逻辑上整合 Wei-Shaw/sub2api v0.2.20 的适用更新，修复 WS 上下文恢复和跨账号续传的三个缺口。

## 修复与改进

- 父响应失效时，在历史完整且尚未向客户端输出内容的条件下，用完整历史恢复当前轮；限制重放次数。
- 换号后保留同一下游连接的旧分支历史，清除旧账号的连接和 turn-state 绑定，按目标分支恢复上下文。
- 压缩恢复后重新判断实际请求大小，超出 WS 阈值时用 HTTP 继续，保留原始计时和计费关系。
- 修复 HTTP 桥接会话身份重复派生，保持头与正文一致、同会话稳定和不同会话隔离。
- 整合管理员密钥权限、注册邮箱黑名单、生图尺寸路由、模型描述、资源保护和请求处理优化；保留既有首字统计、余额处理、自动增量和 Codex 出站规则。
- 支持四段版本的修订号比较。采用运行文件白名单打包，排除测试、夹具、缓存和临时验证产物；加入项目测试与发布规则。

## 验证

- 后端全包回归及修复后服务包复跑：25,187 个场景通过，51 个因环境条件跳过。
- 恢复与会话身份：277 个场景连续三轮，共 831 次通过。
- 前端：384 个测试文件、3,092 个测试通过；类型检查和生产构建通过。
- 本轮额外验证四段版本比较、运行文件白名单、Linux amd64 构建及归档 SHA-256；发布记录包含产物清单。

以上恢复验证使用本地 socket 和受控上游，未进行线上真实账号验收。完整整合与冲突处理见 [整合报告](UPSTREAM_0_2_20_INTEGRATION.md)。

## 安装产物

仅提供 Linux amd64 二进制包（内嵌前端）及 SHA-256 校验文件，没有构建其他平台或容器镜像。GitHub 源码保留必要回归测试，部署压缩包不包含这些测试。

本次按指定名称切换到 `0.2.20.1` 编号，代码基于此前 `0.2.71` 的后续修复。旧版按数值比较可能不提示升级，需明确选择本版本安装，不代表代码回退。

# GN2API v0.2.68

完成 v0.2.67 的线上验收补修：Codex 的站内余额拒绝仍发送终止失败事件，普通请求仍返回 HTTP 403；修正监控捕获 SSE 时把本地余额失败误记成上游 502 的问题。

- 明确的本地余额拒绝标记优先于 SSE 正文的通用上游错误推断。后台记录逻辑 403、实际传输 200/101 和用户侧余额拒绝，不生成虚假的上游 502。
- 保留真正的上游错误和已恢复重试记录；有余额时的转发、重试、切号及上下文续传沿用原逻辑。
- 新增经过完整监控中间件的回归：修复前复现 403 被记成 502，修复后核对状态、传输状态、账号与归因。
- v0.2.67 公网官方 Codex 0.166.0 验收已确认：两名余额不足用户分别通过 HTTP 和 WS 主动请求两轮，均只收到终止额度错误，无自动重连；本版继续复验。

仅发布 Linux amd64 二进制及校验文件。前端和客户端失败协议与 v0.2.67 相同。详见[余额拒绝处理说明](../deploy/balance-denial-repair.md)。

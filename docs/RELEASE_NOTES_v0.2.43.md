# GN2API 0.2.43

修复 HTTP Responses 经 WS 转发时的握手 403 回退，以及工具续传自动增量检查点不完整的问题。

## WS 握手 403 与错误响应

- 不再把所有握手 403 都视为认证失败。对不透明的握手拒绝和已识别的 Cloudflare 拦截，在尚未输出、请求未取消且完整历史可安全回放时，使用已有 HTTP 回退路径。
- 明确的认证、账号状态和结构化权限拒绝继续保留原错误语义。单次握手拒绝不永久禁用 WS；HTTP 同样拒绝时仍按真实失败处理。
- 最终 JSON 错误写出后标记已交付，避免 Responses handler 再拼接一份通用 SSE 错误。

## 工具续传自动增量

- 从已完成的流式输出项补全增量检查点，避免终态输出为空或缺项时，把上一轮工具调用再次作为新增输入发送。
- 校验 function/custom tool 调用和结果的类型、编号及完整配对；遇到冲突、缺项或无法确认的历史时使用完整请求。
- 自动锚点被明确拒绝为缺少工具结果时，仅在完整原请求具备对应结果且尚未输出的条件下，换连接完整回放一次；保留模型、推理档位、工具历史及推理密文声明。
- 检查点仅保留有界指纹，不新增问答正文、图片或推理密文的持久记录。日志区分增量尝试、增量成功和完整回放。

## 验证与附件

- 相关 service、handler、middleware 回归共 1,007 项测试及子用例通过，0 失败、0 跳过，包含本地真实 WS 握手和完整 Responses handler 测试。
- 具体边界与验证范围见 [HTTP Responses 自动 WS 增量](HTTP_WS_INCREMENTAL.md)。本地测试不能代替上线后的真实请求观察，也不保证消除上游拒绝、达到特定缓存率或首字时间。
- 仅提供 Linux amd64 二进制包、构建信息与 SHA-256 校验文件；校验并复用未变更的前端资源，不发布容器或其他平台产物。ModelTrace 扩展保持原版本。

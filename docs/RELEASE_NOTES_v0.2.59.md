# GN2API v0.2.59

修复空闲 WS 长连接持续占用余额预留、导致低余额用户压缩或重连被提前拒绝的问题，并更新首字统计和账号性能观察。

- **WS 余额按轮预留**：一轮完成并计费落地后释放，空闲连接继续保留增量上下文；异步计费期间仍保护余额。同轮重试和换号不重复预留。保留已准入请求允许超额结算、下一轮余额不足再拒绝的规则。
- **明确的余额不足提示**：先发送 `insufficient_quota` WS 协议错误，再关闭连接。本机官方 Codex CLI 0.166.0-alpha.6 的独立本地测试确认，客户端识别额度不足后结束，不反复重连或回退 HTTP。
- **首字口径调整**：普通 HTTP 默认 `semantic`；WS 入口或出口（含 WS→HTTP）采用 `ws_semantic`，明确的推理条目/片段或非空文本、工具等内容开始计时。开始处理通知、空 delta 不计入。删除 `first_event` 设置选项，旧值按 HTTP `semantic` 处理；诊断字段 `first_event_ms` 保留。首字不等于正文可见时间，历史用量不重算。
- **账号性能只观察**：ModelTrace 增加“首字观察”页，根据真实用户流量按账号、模型、推理档位、协议、计时口径及上下文分组，显示样本数和 P50/P95 等统计。不发模型探针、不填写停用阈值、不自动停止调度或加入冷却池。统计只保存在有界内存中，不保存请求正文，重启后重新采集。

WS 余额修复覆盖透传、连接池、HTTP 桥接；已验证计费等待时的并发保护、超额结算后下一轮拒绝，以及 429/401 换号后的工具上下文续传。后端相关回归、前端设置测试与类型检查、扩展页面检查通过。原生客户端兼容验证使用本地模拟服务，不消耗真实模型 token；不代表线上已经部署或完成真实流量验收。

仅构建 **Linux amd64 二进制**，内含重新构建的前端。另附配套 `modeltrace_0.2.59.tar.gz` 扩展包、SHA-256 校验文件和构建记录，不构建额外平台或容器镜像。账号性能观察需主程序和扩展配套更新；本次发布不自动更新服务器。

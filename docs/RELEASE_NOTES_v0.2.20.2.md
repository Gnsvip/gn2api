# Sub2API 0.2.20.2

修复旧压缩上下文在切换账号后被网关误拦的问题，以及上游 WebSocket 空原因断连后的回退处理。

- **密文记录按账号隔离**：一个账号拒绝的加密摘要，不再让同一会话换到其他账号时也被提前拒绝。保留压缩上下文完整性检查；缺少原始历史时不会通过删除摘要继续生成。
- **单一终止错误响应**：压缩恢复已返回 JSON 错误后，阻止接口层再追加 SSE 错误，避免混合响应体。
- **WS 断流后的会话回退**：上游以 1008、空原因关闭连接时，记录账号与会话范围的传输冷却。HTTP 转 WS 的请求尚未输出时可以回退 HTTP；已输出的当前轮不自动重放。后续请求可使用 HTTP，冷却后沿用现有恢复探测。
- **原生 WS 工具续传**：ctx_pool 和 passthrough 会话处于传输冷却时使用已有 HTTP 桥，保留工具调用及结果关系。账号显式关闭 WS 的设置继续有效。
- **测试编译**：将依赖 unit 测试工具的压缩计费用例移入已有的 unit 测试文件，修复普通测试编译失败。

## 验证与产物

- 671 项相关检查通过（含父测试和子用例），覆盖压缩恢复、账号隔离、工具续传、断流不重放、首字统计及接口错误处理。
- 普通模式服务包编译通过；未新增测试文件。
- 仅发布 Linux amd64 二进制包，内含已验证的前端和运行必需文件，不构建容器或其他平台。
- 前端界面、全局 semantic 首字规则及账号独立 first_event 配置未修改，无数据库迁移。

## 边界

本次消除跨账号误拦，不保证任意账号都能解密既有摘要。旧会话若没有可用的完整历史或恢复副本，仍需恢复原始上下文。1008 空原因断连的上游根因尚未确认，本次改进故障后的处理，不将其认定为固定连接寿命或模型能力变化。

# GN2API 0.2.24：自定义测试接口修复

修复 OpenAI Responses 账号测试收到自定义 `prompt` 后仍发送固定 `hi` 的问题。OpenAI Responses 和普通 Anthropic 测试现在会透传提示词；未填写时保留原默认行为。

- 新增管理员能力查询 `/api/v1/admin/accounts/test-capabilities`，独立扩展可先确认兼容性，避免发送无效付费探针。
- 新增 `mode=attribution`：要求有效文本提示词、受支持账号和完整响应；截断、断流或未正常完成不能当作测试成功。
- 归因测试成功后不会触发手工连通性测试的账号恢复操作；401、429 等现有错误与限流保护保留。
- 请求继续使用已有账号测试出站路径，传输类型取决于账号和实际选路。本次没有增加或改变网络身份模拟逻辑。

模型归因算法、页面、定时调度和 SQLite **仍在独立 ModelTrace 扩展中**，没有编入此二进制。单独更新 GN2API 不会出现新的「提示词测试」页面入口；需要另行安装独立扩展包。

验证范围：本地模拟上游的接口和完成事件专项测试；复用既有前端构建。没有执行全量 Go 回归、真实上游请求或生产环境部署。

# Sub2API 0.2.20.10

修复同一用户、Key、会话切换业务分组后无法匹配压缩恢复副本，以及仍在使用的副本被过期或容量淘汰的问题。

- 原历史副本按用户、Key、线程与执行通道验证归属，允许同一会话跨分组恢复；密文指纹、完整压缩窗口、消息内容及工具关系仍严格校验。
- 兼容迁移仍有效的旧格式副本，并持久化更新后的归属。新生成的替换摘要继续绑定生成账号与请求参数。
- 请求使用已知摘要时续期原副本，执行期间保留引用，完成、失败、取消或上下文编辑后释放。续期不会额外保存普通请求正文，资源总量仍有界。
- 记录副本因空闲过期或容量淘汰而清理的原因，不记录聊天正文。

验证：309 项相关后端测试通过（含子用例），覆盖 HTTP、HTTP 转 WS、原生 WS、跨分组与重启恢复、工具续传、账号隔离、活跃引用及释放；Linux amd64 编译通过。端到端验证使用本地模拟上游；线上恢复效果仍需真实故障样本确认。已经删除或从未保存的历史副本不会因升级自动找回。

仅发布 Linux amd64 二进制及嵌入式前端。运行包按明确白名单生成，不含测试、夹具、缓存或验证脚本。

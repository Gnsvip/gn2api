# GN2API 0.2.21

## Codex CLI 0.166.0 出站适配

- 新增正式版 Codex CLI `0.166.0` 的 HTTP 和 WebSocket 出站支持。上一版因未验证该版本而回退旧传输；本版在开启功能并加入账号白名单后，可以进入 Codex 出站通道。
- 纳入官方 Linux x86_64 CLI 的六组离线采集样本，覆盖首次请求、工具调用、HTTP 回退、认证失败后刷新和上下文压缩，共 142 条记录。
- 保留规范 `codex_cli_rs` 身份，并支持采集到的 `0.166.0` 成对 `codex_exec` / User-Agent 身份。已验证的 TLS 结构与现有配置匹配，无需更换 TLS 模板。
- 新增请求头顺序、TLS 握手、WebSocket 压缩帧重放、HTTP zstd 请求体保持以及实际 WS 代理选路的回归检查。
- 保留 `0.163.0` / `0.164.0` 支持。未知版本、alpha 版、身份不匹配或未入白名单的请求继续使用现有传输。

## 启用范围

功能仍默认关闭。部署后需要在现有配置的 `gateway` 节点下合并以下设置，账号 ID 请替换为实际的 OpenAI OAuth 测试账号：

```yaml
gateway:
  codex_egress:
    enabled: true
    account_ids: [123]
```

只对符合 Ubuntu CLI 身份、版本匹配和 `chatgpt.com:443/backend-api/codex/responses` 条件的请求启用。HTTP 使用 TLS 模板和可重放请求体的 zstd 编码；WebSocket 使用对应握手及帧传输。Windows/macOS 身份和其他上游地址不在本次范围内。版本号只增加了正式 `0.166.0`，没有使用通配放行。

## 发行与部署

- 本次发行仓库为 `Gnsvip/gn2api`，提供包含前端的 Linux amd64 程序包、SHA256 校验和构建来源记录。
- 相对 v0.2.20 不新增数据库迁移，不改变计费逻辑、倍率、分组或其他平台转发。
- 不发布 Docker 镜像。后续部署请使用本仓库发行包；继承的上游安装脚本不是本定制版升级入口。
- 本次只发布新版本，生产服务器不更新、不重启。服务器部署须经用户再次确认。
- 如启用后需要回退传输，可关闭 `gateway.codex_egress.enabled` 并按既有方式重新加载程序配置；程序回退可使用上一版发行包，本次没有数据库结构回退操作。

## 验证范围

- 官方 0.166.0 六个离线采集场景通过；strace 未观察到非回环地址连接。
- Windows 定向测试通过；Linux 下传输层、TLS 样本回归及 Codex 出站服务测试通过。需要外网的可选 TLS 测试未启用。
- 前端生产构建、类型检查和 3 项语言资源检查通过；构建保留已有的部分资源包体积告警。
- Linux 下 10 项发行工具检查通过。
- 完整回归期间发现两项既有测试的时序问题：Grok 测试未等待后台缓存写入；CommandCode 测试以时间戳生成缓存键，在 Windows 上可能重复。本版仅修正这两项测试的等待和隔离方式，不改变对应业务逻辑。最终完整测试和发行包启动结果见本版 GitHub Release 及随附的 `build-info.json`。

离线采集和本机测试不等同于真实 OpenAI 账号端到端验证；本次未做真实账号调用、生产数据库/Redis 集成或生产压测。发布不代表已经部署。

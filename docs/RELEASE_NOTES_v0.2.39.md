# GN2API v0.2.39

测试设置现在可以同时保存归因页和自定义题目页的修改。关闭检测后也能编辑模板；Tibo、糖果短答案与画图入口在同一轮结果中展示。主窗口使用右上角关闭按钮和统一保存按钮，窄屏自动换行。

Codex HTTP 建连预算调整为 30 秒，测试整轮仍为 720 秒。页面区分代理、TLS、直连、响应等待、中断及上游繁忙，并消除重复错误说明；每题仍只提交一次。

## 验证与升级

- 扩展 274 项回归通过；浏览器新增两页统一保存、先校验后写入、部分失败重试、未保存关闭确认、同轮三题以及窄屏回归，使用模拟 API，无真实模型请求。
- Go 相关 service、admin handler、repository 单元回归通过；JavaScript 语法和差异检查通过。
- 同时更新主程序和 `20261102-settings-1` 扩展。升级前备份，保留现有设置、结果及留证；主程序与扩展需短暂重启，Nginx 平滑 reload。
- 保存两个页签不是跨接口事务：已成功的页面不会回滚，失败页保留草稿供重试。
- 旧记录不改写；延长连接等待不能修复上游过载，不将本版视为模型身份或能力验收。

# GN2API 0.2.36：检测预算、推理等级与版本更新修复

本版将检测预算和可选推理等级修复纳入正式发行。主程序按 release 构建，页面显示标准版本 v0.2.36；更新检查、回滚版本列表及安装脚本统一使用 Gnsvip/gn2api。

## 主要更新

- 修复带构建元数据的版本号解析：0.2.35+effort-budget.1 不再被误判低于 0.2.19。更新缓存绑定仓库，旧上游缓存不再进入本仓库的更新结果。
- 模型归因与自定义题目页面分别提供 low、medium、high、xhigh，并独立保存；现有配置保持 xhigh。主网关提供对应四档比较协议，档位进入实际请求构造与尝试记录；旧网关不支持时在发起模型请求前报错。
- 初测整轮预算 720 秒；需要补采或确认复测时，从同一轮起点最多 1200 秒。档位变化取消旧轮次的后续请求与结果写入，既有尝试证据保留。
- 页面区分检测超时、上游错误、样本不足、输出超限及指纹库未校准。长轮次结束后等待完整调度间隔，避免连续补跑。
- ModelTrace 配套包为 modeltrace_20261101-effort-budget-1.tar.gz，包含升级工具、测试、指纹数据与许可证，按 MANIFEST 校验。主程序和独立扩展需要配套更新。

## 验证与边界

发布前验证覆盖更新来源、旧缓存隔离、带构建元数据的版本比较、四档请求构造，以及 ModelTrace 的预算、持久化、取消、升级迁移和页面行为。发行附件包含构建来源和校验值。

指纹库尚未完成各档位下的真实校准；延长预算与提供档位选择不代表统计候选已成为确定的模型身份。本版没有新增付费模型请求，也没有完成新的官方 CLI / 网关真实账号配对验收。保留连续 120 秒无数据的传输保护；阻塞读取可能晚于整轮截止返回，但过期结果不会被采纳，也不会继续发起后续请求。

GitHub 正式版本发布并核验后，再使用相同发行附件更新服务器。本次不发布容器镜像。

# GN2API 0.2.35：Codex 出站生命周期与比较测试证据修复

本版修复 Codex 出站传输、OAuth 刷新、出口时区及比较测试证据保存。包含配套的独立 ModelTrace 扩展；主程序与扩展仍分别运行，完整比较功能需要两者配套更新。此次仅发布 GitHub，生产部署另行确认。

## 主要更新

- 每次问答、复测和归因保存独立 attempt_id、完整结果及请求关联，避免后续复测覆盖先前证据；中断和取消保留已取得的数据。
- 比较协议固定请求模型、xhigh、指令、上下文和 HTTP 传输路径；未校准的新条件明确标记“指纹库适用性未验证”。闭集归因候选不再当作已确认模型身份或据此自动停调度。
- 补齐 HTTP/WS 的 401 reload → refresh → replay，记忆永久拒绝的凭据版本，抑制重复旋转；持久化提交后释放旧认证连接，WS 延迟建连重新读取凭据。
- 修复刷新响应缺少 expires_in 时新凭据被误判立即过期；JWT exp 优先，提前五分钟刷新，无已知到期时间时使用 last_refresh 兜底。导入 opaque token 的显式 expires_at 兼容行为保留。
- 辅助接口默认使用 Codex HTTP/TLS 客户端，规范头字段并禁止自动重定向；保留回滚开关。
- 增加自定义 CA 下的 rustls/H2、HPACK 和认证连接池，修复读取、并发、取消、退休与空闲回收问题。CLI 0.166.0 业务 HTTP 请求按实际采样分别建立连接，认证客户端按凭据代际复用。
- 出口时区按账号覆盖或代理/直连探测缓存解析，启动及每小时刷新；代理配置改变、过期或新 IP 缺少时区时不沿用旧关联。按既定策略，原生 CLI 的环境时区也以出口配置为准；未知时区回退明确标记，不能视为 IP 匹配成功。

## 验证范围

- 官方 Linux Codex CLI **0.166.0 / gpt-6-astra / xhigh**：默认 TLS、自定义 CA/H2 各六个受控场景通过严格出站比较。覆盖 WS 首轮、工具续传、HTTP 回退、HTTP/WS 401 刷新、WS 压缩及上下文压缩；逐场景检查 models、连接使用、刷新关联、发送者归属和 TLS。
- 使用实际 CLI、生产网关服务方法和真实本地 socket，合成账号与模拟上游；并非只验证请求构造器。H2 比较还包含头顺序、SETTINGS、窗口及 stream ID；缺少实际录制证据会判失败。
- 后端全量 unit：61 个测试包、24,999 个测试/子测试通过，36 个跳过，0 失败。最后的 H2 连接修正后 repository 整包另行重跑通过（1,149 项，数字与全量重叠）。Linux recorder 67 项通过，embed 前端服务测试通过。
- 发布前 ModelTrace 证据、问答、服务及升级流程回归：177 项通过。扩展发行包包含对应 fingerprint 代码、数据与许可证，并校验 MANIFEST。
- 当前代码包含 0.163.0、0.164.0 和 0.166.0 适配；**0.163.0/0.164.0 尚未对本版完成同等级完整配对验收**。历史样本或版本允许列表不等于本版完整验收通过。

## 已知边界

- 目标账号在当前候选上的真实问答配对尚未完成：此前官方端进入刷新流程，隔离验收阻止旋转生产凭据，未获得有效答案。旧候选结果不沿用。
- 未验证生产部署的认证中间件、调度、数据库及真实上游模型全链路；未运行 race 检测。
- 上游 HTTP 回退匹配，但下游 CLI 在网关接受 WS 后仍可能先重连再回退，握手状态与时序不是完全相同。
- 比较会按关联关系归一化动态 ID、时间和受控地址。通过有限场景不代表所有版本、端点或原始字节无条件 1:1，也不能证明上游真实模型身份。

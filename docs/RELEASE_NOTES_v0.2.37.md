# GN2API 0.2.37：出口时区、Codex 续传与有限采证修复

本版修复实测发现的 Codex OAuth 转发差异，并配套发布 ModelTrace 的有限采证与页面修复。

## 主要更新

- 出站时区以实际出口为准：使用代理时读取该代理的有效出口 IP 时区，直连时读取服务器直连出口。旧账号手动时区不再覆盖出口；缓存失效或出口无法确认时明确回退 UTC，不借用其他出口或旧账号时区。
- 修复 WS 连接预热的握手信息覆盖后续正式轮次的问题。每帧已有的轮次信息优先，握手只用于缺省回填，保留正式请求、工具续传和压缩的类型及时间信息。
- 原生 Codex HTTP/WS 请求保留推理条目 ID、工具结果 ID 与成对调用 ID，避免旧兼容逻辑删除或改写续传关系；API-key 和非原生兼容输入保留原有处理。
- ModelTrace 按账号与固定比较条件仅保存首个正常、首次异常的完整脱敏诊断。重复轮次只留摘要及请求关联，不持续保存逐条 SSE/Base64；已有记录不删除。轻量历史仍会增长。
- 糖果等问答不再将长回答直接铺在弹窗上；完整答案按需分页，尝试记录轻量展示，旧大记录支持流式下载。
- 候选不符与指纹库未校准分别展示，符合条件时在既有预算内复测；未校准结果仍不能认证底层型号或触发归因自动停调度。
- 独立比较工具支持生产 WS 转发、显式账号与代理核对、不可覆盖的审计文件及最终事件记录，仅在显式 comparison_harness 构建中启用。

ModelTrace 配套包为 `modeltrace_20261102-evidence-pair.tar.gz`。沿用上一版可选推理等级与 720 秒初测、最多 1200 秒确认预算；升级完整功能需要主程序和独立扩展配套更新。

## 验证范围

- 官方 Codex CLI 0.166.0 与候选网关使用同一 OAuth 账号、出口、模型、xhigh、指令和上下文，完成真实 WS 首轮/预热/工具续传及 HTTP 工具续传。所测非身份语义字段无差异，工具调用关系和返回结果保留；WS 确认 101 握手且未回退 HTTP。
- WS 首轮、WS 工具续传、HTTP 回退工具续传、HTTP 401 刷新、WS 401 刷新、WS 压缩/上下文压缩，在默认 TLS 与自定义 CA/HTTP2 两组受控环境中通过严格比较；包含 models、连接关系、刷新关联、发送者和 TLS 检查。
- 定向 Go 回归、Linux 基线比较器及 ModelTrace 持久化、预算、迁移、记录浏览和页面检查通过。发行附件中的构建信息记录源码提交、构建工作流与校验值。

真实账号验收使用隔离启动的生产转发实现，不覆盖生产认证中间件、调度、数据库与计费。真实 models 请求成功，但配对 CLI 的目录/bootstrap 数据固定在本地；401 刷新和强制压缩使用合成账号及本地上游。官方明文证据来自 CLI rollout，候选保存最终出站记录，并非解密官方全量线上流量。身份与会话字段允许隔离，不承诺所有请求逐字节相同。

请求保真通过不等于账号能力恢复，也不能证明底层型号。已有异常账号在两侧均答错，不能据此单独归因于网关。私人账号数据与验收流量不包含在公开附件中。

本次仅发布 GitHub 版本；服务器部署须再次确认，不更新容器镜像。

# GN2API v0.2.62

修复流内失败恢复及透明 WS 的后续轮次切号：当当前轮次尚未交付内容、完整历史可重建时，账号返回可恢复的认证、限流或上游服务错误，可切换到其他可用账号，包括明确启用 `http_bridge` 的 HTTP 备用账号。客户端继续使用原 WS 连接，切换后可继续对话和工具续传。

- 重建失败的当前轮次，保留完整输入历史、已完成的助手输出、模型、推理等级、指令和工具调用关系，移除旧账号的 `previous_response_id`。
- 修复旧 WS relay 与 HTTP 桥接之间的客户端读取交接，避免读者争抢、吞掉下一帧或提前关闭客户端连接。
- 前置空事件不再错误地阻止安全切号；已经交付文字、推理、工具或密文的请求禁止重放，避免重复回答或执行工具。
- 同一连接中途更换模型后，重试、使用记录和计费归属保持当前轮次的模型，不再沿用连接最初的模型。失败尝试沿用当前轮次的余额预留。
- HTTP/SSE 路径补齐通知事件与空输出的恢复判断；明确的已输出上游服务失败可交给既有健康计数，仍不能触发内容重放。本版本不自动开启健康冷却。
- 补充有界诊断元数据，记录前置事件类型、实际输出边界、切号判断和输入条数，不新增请求正文日志。透明 WS 的恢复历史仅存于连接内存，超过配置的请求大小上限后禁用恢复，不截断正常流量。
- 清理中、英、日项目介绍页中的赞助商广告、推广横幅和优惠链接。

## 验证

533 个顶层测试通过，含子场景共 1059 项通过，无失败或跳过。覆盖真实本地 HTTP/WS 连接、模拟上游 401/429/502、跨账号连续三轮、工具上下文、读取交接、取消、模型归属和计费预留，以及已输出和历史不完整时禁止重放。

以上属于本地受控测试，不能替代部署后的真实上游验收。没有修改首字计时口径、前端业务功能或 ModelTrace 扩展。

仅提供 Linux amd64 二进制，内含同源构建的前端，附 SHA-256 校验和构建记录；不构建其他平台或容器镜像。

配置与恢复边界见 [WS 换号与 HTTP 备用线路](WS_HTTP_ACCOUNT_FAILOVER.md)。

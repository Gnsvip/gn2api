# GN2API v0.2.69

修复第三方客户端使用 Python-urllib 等默认库标识时，被 API Key 上游返回 Cloudflare 1010、最终显示 502 的兼容问题。

- OpenAI API Key 出站遇到缺失或通用库默认的 User-Agent 时，补为真实应用标识 `GN2API`。HTTP、WS 握手和账号测试共用规则；已有应用标识、账号自定义头及 OAuth Codex 身份规则保留。
- 明确的 Cloudflare 1010 不再消耗同账号的池模式重试次数，允许尝试其他账号；不据此禁用、冷却账号或扣减账号调度健康分。普通 403、401 与 429 保留原有分类。
- 回归覆盖请求头优先级、模型与推理参数保留、完整 handler 两账号切换，以及所有候选均被拒绝时的有限尝试。
- 站内余额拒绝、首字统计、前端与账号配置保持不变。

仅发布 Linux amd64 二进制、构建信息和校验文件。

# GN2API 0.2.42

本版本修复兼容客户端经 OAuth 重建 Codex 请求时的会话接续，并补齐原生 Codex 历史的 WS 自动增量及超大请求提前 HTTP 回退。

## OpenCode 与兼容客户端会话接续

- 调度和 Codex 身份构造共用会话头识别规则，支持 OpenCode 等客户端的明确会话头。同一对话的重试和工具续传保持会话与回合关联，新用户输入仍开启新回合。
- Chat Completions、Messages 的合成前缀、正文元数据和请求头共用同一次解析出的身份；换账号重试会清理旧身份。
- 保留 Chat Completions 正文中的自定义 `prompt_cache_key`，避免被调度会话提示替代。
- 消除最终出站中与标准会话头冲突的旧格式会话头。API key、上游凭据和独立会话之间继续隔离。

详见 [兼容入口会话关联](OPENAI_COMPAT_SESSION_IDENTITY.md)。

## 原生 WS 增量与大请求处理

- 自动增量支持原生 `additional_tools`、`configuration_update` 历史条目，完整比较工具声明及配置；历史匹配且连接有效时，仅发送新增输入。
- `compaction_summary` 要求非空密文并整项比较；`compaction_trigger` 视为上下文切换边界，压缩后先完成一轮完整 WS 请求，再建立新检查点。
- HTTP→WS 先尝试增量，再按最终准备发送的未压缩 JSON 大小检查。默认阈值 15 MiB；达到阈值且具备完整历史时提前使用 HTTP，保留图片、工具调用、模型和推理档位。
- 本地大小检查不写入超限 WS 业务包，也不关闭尚未写入的健康连接。HTTP 回合后若完整历史仍超限，可继续走 HTTP；客户端压缩后重新建立增量检查点。

详见 [HTTP Responses 自动 WS 增量](HTTP_WS_INCREMENTAL.md)。

## 验证与发行附件

- Go 回归覆盖身份一致性、会话/账号隔离、工具续传、原生增量、压缩边界、大小检查和 HTTP 回退；具体测试结果写入 `build-info.json`。
- 先前隔离真实上游验证了增量工具续传、历史图片不重复发送、大包 WS 边界与 HTTP 回退、原生压缩后的检查点重建。测试记录与限制见上述文档。
- 只提供当前服务器所需的 Linux amd64 二进制包，包含经过校验的前端资源，另附构建信息和 SHA-256 校验文件。ModelTrace 扩展保持原版本。

本版本修复已复现的请求构造和续传问题；不承诺特定缓存命中率、模型身份或能力结果。实际用户缓存表现仍需上线后的真实请求验证。

# GN2API v0.2.38：测试超时与问答链路修复

部分长画图测试在约 240 秒被主程序测试入口终止，扩展虽配置 720 秒，仍无法完成；短错误事件缓冲及单题异常结束整轮又使后续 Tibo 等题目未被执行。

本版将主程序归因/问答测试入口上限统一为 720 秒，保留调用方更早截止时间；管理能力接口返回实际配置。扩展及时读取短 SSE 事件，将网关超时、连接中断和上游处理错误分别显示。在整轮 720 秒预算内，一道题失败后继续后续独立题目，每题只请求一次；取消、路由变化和整轮超时仍终止检测。不完整轮次保持黄色，不因错误停止账号调度。

配套扩展 `20261102-timeout-1`，必须与主程序一起更新。保留单次采样、用户配置的连续不符停止规则、正常/异常有限留证和已删除账号清理；不改写历史结果。无需主库或扩展数据库结构变更。

## 验证

- 扩展 261 项测试通过，包含本地分块 HTTP 服务的短 SSE 事件回归、异常后继续 Tibo 且不重试、整轮截止及路由变化中止。
- Go 回归从真实测试入口检查最终上游请求的 720 秒截止时间、较早父级截止时间，以及超时/断流/上游错误分类。
- 浏览器模拟接口验证错误标签与页面操作；发布构建覆盖五个平台，包内文件与源码提交按 SHA256 核验。
- 未新增真实模型调用，本次不认证底层型号或声明能力恢复；历史中的旧“上游错误”不会自动重分类。

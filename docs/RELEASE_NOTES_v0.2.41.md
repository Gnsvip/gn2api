# GN2API v0.2.41

普通 HTTP Responses 客户端使用已有的上游 WS 通道时，现在可自动增量续传：同一连接、会话及参数一致，且完整历史前缀匹配时，只发送新增 input 和 previous_response_id。客户端无需逐个修改配置。

- 检查点绑定实际租用的 WS 连接，10 分钟过期；按 API key、分组及线程隔离，保留模型、推理档位、上下文与工具调用关系。
- 连接失效、历史被编辑、模型或参数变化时使用完整上下文。自动响应锚点失效且尚未向客户端输出时，保留完整工具历史重试；允许 HTTP 回退的情况同样携带完整请求。
- 检查点仅在内存保留摘要及必要关联信息，不保存问答正文，不新增数据库或 Redis 记录。完成日志增加增量是否采用及原因两个字段。
- 原生 WS 续传保持现有处理；本次不将所有端点强制改为 WS，也不保证上游缓存率或模型能力。

验证：874 项相关测试及子用例通过，另补测 JSON/SSE 下 function/custom tool 三轮续传通过；覆盖过期、断连、跨账号作用域、并发分支、旧响应失效及全量恢复。未发起生产模型测试，未运行 race 检测。

发行附件仅提供 Linux amd64 二进制及构建来源、校验文件，不构建其他平台或容器镜像。前端复用 v0.2.40 已校验产物，构建时验证前端源文件完全一致；ModelTrace 扩展不变。

传输规则与边界见 [HTTP Responses 自动 WS 增量续传](HTTP_WS_INCREMENTAL.md)。
